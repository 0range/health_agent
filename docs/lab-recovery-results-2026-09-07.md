# Распознавание: результат восстановления

TL;DR: исправление работает на настоящем архиве. Добавлены 83 кандидата;
13 из них сверены с оригинальными PDF и подтверждены. В истории теперь
147 подтверждённых значений вместо 134. Полным распознаванием архива это не является.

## Что изменилось

- Ошибка одной строки больше не уничтожает остальные корректные строки ответа.
  Сама страница остаётся неполной — система не скрывает пропуски.
- Поддержаны две конкретные раскладки таблиц PDF. Из них восстановлено 15 строк.
- Из сохранённых ответов модели извлечено ещё 68 кандидатов без новых запросов.
  Кандидат — не обязательно новый уникальный медицинский факт или готовая точка графика.
- Ранее подтверждённые результаты остаются видимыми, даже если в том же документе
  появились строки, ожидающие проверки. Все прежние 134 значения сохранены.

Из 86 ожидающих проверки строк 16 были до этого прохода, 70 добавлены сейчас.
13 подтверждений сделаны после индивидуальной визуальной сверки значений,
единиц, референсов и дат в четырёх оригинальных документах; автоматического
массового подтверждения нет. Это проверка переноса данных, не медицинский диагноз.

## Что ещё не завершено

89 страниц по-прежнему требуют технического внимания: 64 с невалидным ответом,
14 с частично восстановленным, 5 с оборванным ответом, 2 с неизвестным исходом
запроса и 4 с проблемой текста/OCR. Это не 89 полностью потерянных анализов:
часть страниц уже дала подтверждённые результаты, часть — не таблицы анализов.

Остаются сверка кандидатов с источниками, обработка оборванных ответов и
отдельных сложных страниц. В одном восстановленном бланке нет даты забора:
дата подписи не подставлялась вместо неё. Действий пользователя для выполненного
восстановления не потребовалось; спорные данные не выданы за достоверные.

## Проверки

1 585 тестов прошли; Ruff и mypy — без ошибок. Пять прежних предупреждений
PyMuPDF/SWIG остаются. Независимое итоговое ревью — без замечаний.
Тесты с PostgreSQL выполнялись в изолированных временных базах.

Перед изменениями сделана локальная резервная копия. Счётчик облачных запросов
остался 255, дневной предел — 20; новых запросов восстановления не было.
Обновлены управляемые запросы Metabase. Три бота опрашивают Telegram без ошибок.
Первый запуск синхронизации Sheets вернул ошибку; повтор завершился успешно,
147/86 строк подтверждены отдельным чтением через Google Sheets API.

Оригиналы, медицинские данные, кэш модели и журнал индивидуальных проверок
остались локально; в GitHub публикуются код, тесты и это описание без значений анализов.
