# Где лежит проект

С 7 сентября 2026 всё относящееся к Health Agent хранится внутри одной папки
`VibeCoding/health-agent`. Соседние проекты не перемещались.

```text
health-agent/
  src/, tests/, docs/           код, проверки и документы проекта
  data/                        локальные данные и оригиналы, не в Git
  .env                         локальные настройки, не в Git
  .superpowers/worktrees/      рабочие копии веток, не в Git основного дерева
  .playwright-cli/             локальные браузерные артефакты, не в Git
    legacy-workspace/          прежние артефакты из общей директории
```

12 прежних соседних папок `health-agent-ИМЯ` перенесены штатной командой
`git worktree move` в `.superpowers/worktrees/ИМЯ`:

`automation`, `cli-fix`, `lab-extraction`, `oauth-site`, `panel-drive-config`,
`panel-polish`, `questions`, `reminders`, `sheets`, `telegram-capture`,
`telegram-russian-ux`, `telegram-service`.

Для каждой проверены сохранность HEAD, состояния файлов и diff. Ветки и файлы
не удалялись. В браузерный архив перенесены 16 файлов Health Agent с проверкой
контрольных сумм; в общей `.playwright-cli` оставлены только прежние июльские
артефакты других работ.

Основная папка приложения не переезжала: пути к базе, настройкам и запущенным
сервисам прежние. После переноса проверены доступность панели/Metabase и свежий
heartbeat Telegram. Повторные авторизации не выполнялись.

Новые рабочие копии создаём **только внутри** `.superpowers/worktrees/`, не рядом
с проектом. Перед возобновлением разработки в перенесённой копии следует обновить
её виртуальное окружение: старые локальные `.venv` могут содержать абсолютные пути.
Это не относится к окружению основного приложения, которое не перемещалось.

В GitHub публикуются код и документация, а не локальные рабочие копии, браузерные
сессии, медицинские файлы или секреты. Перенос папок — локальная организация,
он не меняет адрес репозитория и размещение OAuth-сайта в ветке `gh-pages`.
