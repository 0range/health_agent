# Qingping Collection Implementation Plan

> Execute inline, using the already approved cloud connection flow. Keep credentials and live readings outside Git.

**Goal:** Collect the configured Qingping monitor into Health Agent every minute.

**Architecture:** An HTTP client handles OAuth and paginated reads; a service maps
raw records into existing PilotStore records with durable cursor and room history.
CLI commands configure, sync, move, inspect and install a dedicated launchd job.

**Tech Stack:** Existing Python/httpx/Pydantic/SQLAlchemy/PostgreSQL/launchd.

## Global Constraints

- One explicitly selected device/profile per installation; no secrets in logs/Git.
- One-day history windows; 10-minute overlap plus hourly 24-hour reconciliation; at most seven new days per execution.
- Keep the existing four-hour automation job unchanged.
- Preserve raw fields, measurement timestamps, source identity and TVOC index units.
- No automatic health advice or new notifications in this increment.
