# Полезная сводка и состояние системы

TL;DR: утверждён гибрид — проверяемые расчёты + объяснения с источниками + AI-резюме. Пользователь также разрешил отправку медицинского текста в OpenAI и запросил общий хелсчек по двум профилям. Дополнительного согласования этих решений не требуется.

## Полезная сводка

Один read-only snapshot на профиль: требует внимания; в пределах референса/стабильно; данных недостаточно. До пяти приоритетов, с датой, источником, объяснением и осторожным следующим шагом. AI не меняет вычисленные статусы и не ставит диагнозов.

Анализы сравниваются только с диапазоном исходной лаборатории и в исходных единицах. Только verified участвуют в медицинской сводке; needs_review показаны как пробел качества, а не патология. Старые анализы доступны с честной датой. Нет диапазона — нет вывода «норма». Квалификаторы, нечисловые/неполные результаты не превращаются в точные числа.

WHOOP: последние семь полных дней против предшествующих 28 дней, минимум 14 валидных дней для базы. Сон, recovery, HRV, пульс покоя, strain. Вес — текущий снимок, дата синхронизации не дата взвешивания. Изменения относительно личной базы не диагноз и не доказательство причины.

## Страница состояния

В существующей локальной панели /healthcheck: отдельно каждый реально созданный профиль. WHOOP: последняя запись и синхронизация, объём; медицина: последние даты документов/анализов, количество проверенных и ожидающих; Telegram: привязка отдельно от живого общего poller; Drive/Gmail/Sheets: их существующие локальные статусы. Не создавать фиктивный профиль Ксюши и не показывать её подключённой до фактической авторизации.

Чтение страницы не вызывает внешние API и не изменяет данные. Недоступный источник не валит страницу целиком. Русский интерфейс, причины и следующий шаг; нет токенов, медицинских значений и сырых ошибок. Обновление вручную достаточно для v0.1; время проверки видно. Локальная панель — доверенный владельцем Mac общий экран, не публичный портал двух пользователей.

## Проверка

Изоляция профилей, пустой профиль, отказ БД/источника, просроченные данные и мёртвый poller; единицы/границы/старые и непроверенные анализы; личная база WHOOP; smoke на локальной базе без раскрытия медицинского текста.
