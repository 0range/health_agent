# Еда: фото, комментарий, напоминание, итог

Пользователь подтвердил этот сценарий в чате 7 сентября. Это уточнение интерфейса
поверх установленной базы, не новая архитектура. Команды остаются запасным входом.

1. Фото сохраняется и получает короткий отклик. Между фото <40 минут — один приём, >2,5 часа — новый; 40–150 минут включительно — уточнить один раз. Не нужно выбирать категорию или взвешивать порцию. Все фото одного приёма сохраняются; десерт может быть отдельным фото. Оценка окончания = последнее фото +20 минут, напоминание отсчитывается от неё; комментарий сам по себе время не сдвигает.
2. Следующий комментарий о фото дополняет этот приём, не создаёт новый и не перезапускает интервал. Явное сообщение о новой еде создаёт новый приём. При реальной неоднозначности — один короткий вопрос, оригинал не теряется.
3. Напоминание приходит автоматически по существующему режиму. Отмены, паузы, тихие часы и защита от повторов сохраняются.
4. По воскресеньям вечером бот сам присылает короткий разбор недели: регулярность, удобство/отступления от выбранного режима, состав тарелки, оценки нутриентов, разнообразие. Только по записанному; отсутствие фото не означает голодание.
5. Фото, комментарии, время, исправления и исходный разбор модели остаются в локальной базе/архиве без удаления через две недели. Нутриенты — оценки; неизвестное не становится нулём.
6. Общие вопросы и связь питания со сном/весом — в основном Health Agent. Он получает ограниченную выжимку фактов о еде; не копирует весь чат и не выдумывает причины.

Из чата нутрициолога не включаем новые запреты без согласования. Действует последняя
утверждённая пользователем версия; исторические исключения остаются материалом для обсуждения.

Дополнение пользователя: тренировочный бот сам присылает ориентировочный план
на следующую неделю в воскресенье вечером. Стартовые предпочтения сохраняются
приватно как пользовательская цель; план остаётся предложением, принятие не требуется
для получения ориентира. Совместить с уже существующей недельной рефлексией,
не отправлять два длинных отдельных сообщения. План обсуждается обычным текстом:
вопрос о нём не меняет расписание, явная просьба перенести/заменить занятие создаёт
обновлённый черновик с сохранением предыдущего. Без обязательных команд.

Приёмка: фото → два комментария → один приём с прежним временем; фото через20мин
→ тот же приём, через3ч → новый; через1ч → уточнение; вопрос не становится едой;
перезапуск не теряет комментарии/напоминание;
недельный разбор доставляется один раз; основной бот видит пищевые факты только своего профиля.
