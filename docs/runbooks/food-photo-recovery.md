# Восстановление калорий после дополнительного фото

Исправление 28 сентября 2026: второе фото того же приёма пищи больше не удаляет
общую оценку калорий только из-за числа сохранённых наблюдений.

Модель возвращает `analysis_scope=whole_meal`, когда рассчитан весь приём.
Приложение проверяет, что ответ содержит прежние ингредиенты после явных
исправлений и что у предыдущих фото есть распознанный состав. Такая оценка
заменяет общую оценку один раз. Она не прибавляется к старому итогу.
При повторном виде тарелки или фрукта продукты не должны учитываться дважды.
Неполный ответ, например только яблоко после основного блюда, не становится
калорийностью всего обеда. Исходные фото и их первые результаты сохраняются.

При неудаче или невалидном JSON сохраняется `last_successful_analysis`.
Бот показывает прежнюю оценку с явным пояснением, что последнее фото/уточнение
ещё не вошло в новый расчёт. Она не выдаётся за текущий полный итог.
Повторная обработка использует тот же приём и исходные времена события.

Для OpenAI добавлены безопасные диагностические коды и один ограниченный повтор
при временной ошибке — см. [настройку моделей](openai-models.md).
Первоначальную причину upstream-сбоя 28 сентября установить точно нельзя:
старый журнал сохранял только `ValueError`. Повтор того же запроса прошёл.
Ошибка локального обнуления нутриентов при нескольких фото воспроизведена
отдельным регрессионным тестом.

Проверены основной приём плюс фрукт, повторный вид, неполный ответ, отсутствие
разбора предыдущего фото, временная ошибка, неверный JSON и восстановление без
дублирования приёма. Также проверен полный путь на сохранённом пользовательском
фото в изолированном хранилище; личные данные и результаты не находятся в git.

Проверка: 882 теста затронутых модулей и ещё 3 проверки границ повторов/неполного
распознавания прошли; Ruff и mypy на изменённом коде прошли. Исправление установлено,
исходная запись восстановлена атомарно после сверки неизменности данных. Сохранены
приватная резервная копия и запись аудита; число приёмов, исходные фото и время
еды не изменены. Ручная отправка сообщений в Telegram не выполнялась.
