# Дашборд WHOOP

Локальный дашборд показывает восемь независимых карточек выбранного профиля:

- Recovery — процент восстановления WHOOP;
- strain — нагрузка по шкале WHOOP 0–21;
- HRV — RMSSD в миллисекундах;
- пульс покоя — удары в минуту;
- длительность основного сна — часы;
- выполнение потребности во сне — доля рассчитанной WHOOP потребности, а не
  общая оценка качества сна;
- эффективность основного сна — проценты;
- вес — один последний валидный снимок в килограммах и время его получения.

Первые семь карточек — отдельные временные ряды: дата и ровно один показатель.
Так линии читаются согласно обычной семантике
[линейных графиков Metabase](https://www.metabase.com/docs/latest/questions/visualizations/line-bar-and-area-charts).
Вес намеренно показан таблицей одного снимка, а не придуманной историей или
агрегацией. Числовые визуализации Metabase предназначены для одного значения;
их поведение описано в
[документации Metabase](https://www.metabase.com/docs/latest/questions/visualizations/numbers).

## Открыть локальный дашборд

Запустите повторяемую команду для нужного профиля:

```bash
uv run health-agent dashboard setup-whoop --profile-id PROFILE_UUID
```

Команда печатает `url=http://127.0.0.1:53000/dashboard/...`; откройте этот URL в
браузере. Повторный запуск обновляет управляемые карточки на месте, сохраняет ID
дашборда и карточек, не удаляет пользовательские карточки и не меняет их раскладку.
Для профиля не по умолчанию в именах Metabase используется полный UUID.

## Как выбираются данные

Для каждого дня берётся последняя валидная запись, а не среднее. Записи без
оценки `SCORED`, значения вне допустимого диапазона, naps и будущие локальные даты
не показываются. Невалидное более позднее значение не скрывает более раннее
валидное значение того же дня. Значения за сегодня могут измениться после
следующей синхронизации.

`observed_at` рядом с весом означает время получения снимка от WHOOP, а не
подтверждённое время взвешивания. Пустые значения не заменяются нулями.

## Ограничения

Показатели — наблюдения из WHOOP, не диагнозы и не доказательства причин или
следствий. Дашборд не использует OpenAI и не даёт медицинских интерпретаций.
История веса отсутствует у текущего endpoint WHOOP, поэтому отображается только
актуальный снимок. Анализы, многолетние медицинские графики и проверка извлечённых
показателей находятся вне области этого дашборда.
