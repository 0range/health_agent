# Health Agent

Личный Health Agent, который работает на Mac и общается через Telegram.

## Первая версия за 30 секунд

**Собирает:** медицинский архив из Google Drive, новые медицинские письма Gmail, WHOOP, документы и наблюдения из Telegram.

**Хранит:** исходники и нормализованные данные в локальном PostgreSQL с указанием происхождения и качества.

**Показывает:** анализы и очередь проверки в Google Sheets; анализы, сон, recovery и тренировки — в Metabase.

**Помогает:** отвечает в Telegram на открытые вопросы по личной истории, предлагает, что проверить, и присылает подтвержденные напоминания.

**Работает автономно:** сам классифицирует, устраняет дубли, повторяет синхронизации и сообщает только о проблемах, где нужно действие пользователя.

**Готово, когда:** реальные документы, Gmail, WHOOP, Telegram-вопросы, новые файлы и напоминания проходят сквозные сценарии, а перезапуск Mac ничего не ломает.
