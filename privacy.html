Privacy Policy

Effective September 5, 2026

Purpose

Health Agent is a personal, local-first application used by people who explicitly install it and connect their own accounts. It helps a user organize personal health documents, wearable records, laboratory results, reminders, and questions.

Google data

With explicit consent, Health Agent reads files only from Google Drive folders configured by the user and reads Gmail messages to identify health-related documents or appointment information. It does not modify or delete Drive files or Gmail messages. Google Sheets access is used to create and update the user's Health Agent spreadsheet.

Storage and use

Imported data and authorization credentials are stored on the user's own computer. Confirmed laboratory data may also be written to a spreadsheet in the user's Google account. Data is used only to provide the requested Health Agent features. It is not sold, used for advertising, or shared with data brokers.

Processors

When AI features are enabled, selected question context or document text may be sent to the OpenAI API solely to generate the requested answer or structured extraction. Telegram carries messages exchanged with the user's private bot. Each provider processes data under its own terms and privacy policy.

Retention and deletion

Data remains on the user's computer until the user removes it. The user may revoke Google access from Google Account permissions at any time and may delete the local profile or generated spreadsheet.

Security and limitations

Health Agent uses profile separation, least-privilege Google scopes, private local credential files, and explicit review before uncertain medical values are confirmed. No system can guarantee absolute security. Health Agent is not a medical provider and does not replace a clinician.
